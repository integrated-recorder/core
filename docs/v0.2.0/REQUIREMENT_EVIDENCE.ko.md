# v0.2.0 Requirement-to-Evidence Matrix

이 표는 개발 브랜치 `feat/v0.2-m0-foundation`의 구현 코드 체크포인트 `0b3f882`를 기준으로 명세, 제품 경로, 테스트 증거를 대조한다. 이후 문서 전용 변경은 코드를 바꾸지 않았다. `LOCALLY VERIFIED`는 해당 행에 명시한 시험 범위만 뜻하며 마일스톤 전체 완료를 뜻하지 않는다. `.research/`는 추적되지 않는 연구 파일로 코드 증거에 포함하지 않는다.
