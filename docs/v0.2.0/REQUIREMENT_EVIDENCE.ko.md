# v0.2.0 Requirement-to-Evidence Matrix

이 표는 개발 브랜치 `feat/v0.2-m0-foundation`의 구현과 제품 경로를 요구사항별 검증 체크포인트에 연결한다. 각 검증의 정확한 코드 SHA는 실행 증거에 별도로 적으며, 다른 SHA의 결과를 자동으로 승계하지 않는다. `LOCALLY VERIFIED`는 해당 행에 명시한 시험 범위만 뜻하며 마일스톤 전체 완료를 뜻하지 않는다. `.research/`는 추적되지 않는 연구 파일로 코드 증거에 포함하지 않는다.
